# HTML 坦克大战

一个使用纯 HTML、CSS 和 JavaScript 实现的经典坦克大战小游戏。

## 在线试玩

直接在浏览器中打开 `index.html` 即可开始游戏。

## 操作说明

- **WASD** 或 **方向键**：移动坦克
- **空格键**：发射炮弹

## 游戏特性

- 玩家坦克与敌方坦克对战
- 砖墙与钢墙地形障碍
- 子弹碰撞与爆炸粒子效果
- 得分、生命和关卡系统
- 简单的敌方 AI 自动巡逻与射击

## 技术栈

- HTML5 Canvas
- 原生 JavaScript（ES6+）
- CSS3

## 本地运行

```bash
git clone https://github.com/YOUR_USERNAME/tank-battle.git
cd tank-battle
open index.html
```
